## 1. 小说概述

### 1.1 基本信息

- **中文标题**: 末日
- **英文标题**: Doomsday
- **副标题**: 生存与抉择
- **类型**: 末日生存互动小说
- **视角**: 第二人称（"你"）

### 1.2 故事简介

这是一个末日生存题材的互动小说游戏。玩家扮演一个在末日废墟中醒来的幸存者，在资源匮乏、危机四伏的环境中做出一系列生存抉择。每一个选择都可能导致不同的后果，甚至生死攸关。

### 1.3 核心主题

- **生存**: 在恶劣环境中寻找食物、水和庇护所
- **抉择**: 道德困境和生存本能的冲突
- **后果**: 每个选择都有相应的结果
- **人性**: 在极端环境下的人性考验

## 3. 功能需求

### 3.1 阅读功能

**FR-001**: 显示页面内容
- 显示背景图片
- 显示文字内容（支持换行）
- 显示页标题（可选）
- 文字以打字效果呈现
- 打字完成后显示选择框

**FR-002**: 分支选择
- 显示所有可选选项
- 每个选项显示 icon 和 text
- 点击后跳转到目标页
- 需要物品的选项仅在拥有物品时显示

**FR-003**: 进度保存
- 自动保存阅读进度
- 刷新后恢复进度
- 提供"重新开始"选项

---

### 3.2 HP 机制

**FR-HP-001**: 血量显示
- 初始血量为 10 点
- 左上角显示红心和血量数值
- 血量变化时有视觉反馈

**FR-HP-002**: 血量变化场景
- **扣血场景**: 跌落、打架、被击中、危险环境
- **加血场景**: 休息、吃饭、医疗、安全区域

**FR-HP-003**: 死亡结局
- 血量 <= 0 时触发死亡
- 显示死亡结局页面
- 提供重新开始选项

---

### 3.3 物品机制

**FR-ITEMS-001**: 物品显示
- 右上角显示当前物品图标
- 可食用物品用绿色框标识
- 点击可食用物品可食用并加血

**FR-ITEMS-002**: 拾取物品
- 某些场景有一个或两个物品可拾取
- 只能拾取一个或都不拾取
- 拾取后物品加入背包

**FR-ITEMS-003**: 物品使用
- 食物类物品可以食用
- 食用后物品消失并加血
- 工具类物品用于解锁选项

**FR-ITEMS-004**: 物品锁定选项
- 某些选项只有指定物品才能出现
- 没有物品时选项完全隐藏

### 3.2 视觉要求

**FR-VISUAL-001**: 末日废土风格
- 灰暗色调
- 破败场景
- 写实风格

**FR-VISUAL-002**: 图片质量
- 分辨率：1328x1328 或更高
- 格式：JPG/PNG
- 文件大小：< 2MB

## 5. 内容规划

### 5.1 章节结构

**第 1 章：觉醒**
- 第 1 节：陌生的清晨（3 页）
  - 初始血量：10
  - 可拾取物品：面包（+2HP）
- 第 2 节：探索环境（3 页）
  - 扣血场景：搜索受伤（-1HP）

  - 需要钥匙的选项：打开门
  - 扣血场景：下楼摔倒（-2HP）

**第 2 章：生存**（规划中）
- 第 1 节：寻找资源
  - 可拾取物品：水、食物
  - 加血场景：进食（+2HP）
- 第 2 节：遭遇危险
  - 扣血场景：战斗（-3HP）
  - 需要物品：手枪（解锁战斗选项）
- 第 3 节：建立庇护所
  - 加血场景：休息（+3HP）

**第 3 章：希望**（规划中）
- 第 1 节：发现信号
- 第 2 节：决定前往
- 第 3 节：新的开始

### 5.4 HP 和物品设计原则

**HP 设计原则**:
1. **平衡性**: 平均每次扣血 1-2 点，加血 2-3 点
2. **紧张感**: 关键抉择前设置扣血场景
3. **奖励机制**: 探索隐藏区域可获得食物加血
4. **死亡惩罚**: HP 归零进入死亡结局，需重新开始

**物品设计原则**:
1. **必要性**: 关键物品解锁必要剧情分支
2. **策略性**: 多个物品时只能选择一个，需要权衡
3. **消耗性**: 食物类物品使用后消失
4. **持久性**: 工具类物品可重复使用

**典型场景设计**:
```
场景：废弃超市
- 可拾取：面包（+2HP）、水（+1HP）- 只能选一个
- 扣血：货架倒塌（-2HP）
- 选项：
  - "搜索货架" → 触发扣血，随机获得物品
  - "离开" → 安全但无收获
  - "用撬棍打开后门" → 需要撬棍，进入隐藏区域
```

## 6. 视觉风格

### 6.1 色彩方案

- **主色调**: 灰褐色、铁灰色、暗棕色
- **强调色**: 暗红色（危险）、昏黄色（希望）

1. **室内场景**: 破旧房间、废弃建筑、地下室
2. **室外场景**: 城市废墟、荒野、公路
3. **特殊场景**: 回忆、梦境（柔化处理）
