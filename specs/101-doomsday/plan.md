# 小说《末日》创作方案

**版本**: v1.0.0  
**日期**: 2026-04-05  
**状态**: 初稿  

---

## 1. 创作目标

### 1.1 内容目标

- 完成第 1 章全部内容（9 页）
- 所有选择支有明确目标
- 生成封面和所有背景图
- 确保导航无断裂

### 1.2 质量目标

- 文字流畅，代入感强
- 图片风格统一（末日废土）
- 选择支有意义
- 读者体验良好

---

## 2. 创作流程

### 2.1 内容创作

```
1. 编写章节大纲
2. 编写每页内容
3. 设计选择支
4. 校验导航链接
5. 创建 JSON 文件
```

### 2.2 图片生成

```
1. 列出所需图片清单
2. 编写每张图的提示词
3. 调用 bailian-image 生成
4. 下载并保存到正确路径
5. 更新 JSON 中的路径引用
```

## 4. 图片清单

### 4.1 必需图片

| 图片名称 | 用途 | 提示词关键词 |
|---------|------|-------------|
| cover.jpg | 封面 | 末日城市废墟，灰暗天空，破碎建筑 |
| room.jpg | 房间背景 | 破旧房间，床铺，桌子，破碎窗帘 |
| hallway.jpg | 走廊 | 昏暗走廊，剥落墙皮，废弃建筑 |
| stairs.jpg | 楼梯间 | 破旧楼梯，铁栏杆，灰尘 |
| lobby.jpg | 大厅 | 废弃大楼大厅，破碎玻璃，杂草 |

### 4.2 生成顺序

1. 封面图（优先级最高）
2. 房间背景（第 1 节必需）
3. 走廊、楼梯、大厅（第 2 节）
4. 其他场景（第 3 节）

```
        ├── 004.json
        ├── 005.json
        ├── 006.json
        ├── 007.json
        ├── 008.json
        └── 009.json
```

### 5.2 路径规则

- books.json 中的路径：`doomsday/images/cover.jpg`
- book.json 中的路径：`images/cover.jpg`
- 页面 JSON 中的路径：`../../images/backgrounds/room.jpg`

## 6. 质量标准

### 6.1 内容质量

- 每页内容 100-300 字
- 选择支描述清晰（5-20 字）
- 导航链接 100% 正确
- 无错别字和语法错误

### 6.2 图片质量

- 分辨率 ≥ 1328x1328
- 风格统一（末日废土）
- 色调协调
- 无明显瑕疵
